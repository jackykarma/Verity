## 先纠正一个认知

你说 `invalidate → onDraw 中间经历了 canvas 产生绘制然后给到 Surface`——这个方向对，但中间缺了关键的一环：

**`invalidate()` 不会直接触发 `onDraw()`，它只是通过 Choreographer 预约了"下一个 Vsync 到来时执行绘制"。**

完整链路是：
```
invalidate()
  → ViewRootImpl.scheduleTraversals()
    → Choreographer.postCallback(TRAVERSAL, ...)
      → 等待下一个 Vsync
        → Choreographer.doFrame()
          → ViewRootImpl.performTraversals()
            → measure → layout → draw → onDraw()
```

Choreographer 就是这个"等待 Vsync，然后统一触发"的调度中心。
