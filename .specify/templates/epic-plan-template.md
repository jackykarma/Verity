| 指标 | EPIC 级预算上限 | 度量口径 | 分配原则 |

### 7.2 内存约束

| 指标 | 约束要求 | 说明 |
|------|----------|------|
| **开机内存增量** | **零增长** | 不引入常驻后台进程/服务；不增加开机自启组件 |
| **运行时内存上限** | [≤ X MB（PSS）] | 功能活跃期间的峰值内存不得超过此上限 |
| **退出后释放** | **必须及时释放** | 退出功能后不得持有大对象/Bitmap/缓存；无内存泄漏 |
| **泄漏检测** | [LeakCanary / Memory Profiler] | 实现阶段须配置泄漏检测工具并通过验证 |
