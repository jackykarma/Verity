# 英语学习

围绕英语主题输出可学习文档，帮助用户建立“理解、辨析、输入、输出、练习、复盘”的闭环。

## 学习方法

始终遵循以下方法：

1. 以“可理解输入 + 可输出表达”为主线，而不是只背规则。
2. 先解释意义和使用场景，再讲规则和形式。
3. 用最小对比帮助区分相近词、相近语法和相近表达。
4. 用例句和改写帮助迁移，而不是只给定义。
5. 用主动回忆和小练习固化知识，每篇必须有练习题。
6. 深入模式必须形成“理解 -> 模仿 -> 变体 -> 产出 -> 纠错”的学习闭环。

## 默认行为

如果用户只输入一个领域或主题，没有补充更多要求，默认按以下规则执行：

- 学习程度默认使用 `系统深入`
- 学习目标默认包含：`能讲给别人听`、`能实战`、`能画图`
- 输出要求默认使用：`先生成学习地图`

因此，除非用户显式修改，否则不需要反复追问“学到什么程度”“学习目标是什么”“是否先出学习地图”。

## 输入要求

至少明确以下信息；如果用户未明确补充，则使用默认行为：

- 输入层级：`领域` 或 `子主题`
- 学习主题：如 `一般过去时`、`虚拟语气`、`技术英语阅读`、`发音连读`
- 学习深度：默认 `deep`
- 学习目标：默认是“能讲给别人听、能实战、能画图”

如果输入的是大领域，如 `英语`、`技术英语`、`英语口语`、`英语语法`，不要直接展开多篇正文，先产出学习地图，再让用户选择子主题。
如果主题过大，优先缩小到一个语法点、一个表达族、一个技能点或一个场景。

## 输出策略

先判断当前输入属于哪一层：

### 领域级输入

当用户输入的是领域而不是单一主题时，先输出 1 篇 `领域学习地图.md`，不要直接展开多个子主题正文。

`领域学习地图.md` 必须包含：

- 这个领域在学什么
- 为什么值得学
- 适合什么目标的人学习
- 前置知识
- 知识树或主题树
- 推荐学习顺序
- 子主题分级与标签
- 每个子主题解决什么问题
- 哪些主题适合先学
- 下一步可选输出主题

学习地图中的每个子主题都尽量标注以下信息：

- 难度：`入门`、`进阶`、`深入`
- 优先级：`建议优先`、`按需学习`、`可后置`
- 适合目标：如“打基础”“提升阅读”“提升表达”“应对考试”
- 前置知识：进入该主题前最好先掌握什么
- 是否可跳过：`否`、`部分可跳过`、`可跳过`
- 产出收益：学完后能解决什么问题

如果用户没有指定子主题，就停在学习地图这一层，等待用户选择下一步。

### 子主题级输入

当用户输入的是明确子主题，如 `虚拟语气`、`一般过去时`、`技术英语阅读`、`连读`，再根据深度输出 `主题总览.md` 或多篇学习包。

## 输出模式

以下模式仅适用于“已经明确子主题”的情况：

### `quick`

输出 1 篇 Markdown 文档，帮助用户快速理解并马上上手练习。文件名必须使用中文，默认使用 `主题总览.md`。

### `deep`

输出 3~6 篇 Markdown 文档，组成学习包。文件名必须使用中文。默认建议文件：

- `00-学习地图.md`
- `01-背景含义与核心规则.md`
- `02-用法模式与对比辨析.md`
- `03-输入输出与练习.md`
- `04-常见错误与纠正.md`
- `05-自测与延伸学习.md`

## 文件命名与配图要求

- 所有学习文档统一输出到 `docs/learn/英语/` 目录下。
- 领域级文档默认保存为 `docs/learn/英语/领域学习地图.md`。
- 子主题级文档必须按主题创建子目录，保存到 `docs/learn/英语/[子主题名]/` 下。
- `quick` 模式默认保存为 `docs/learn/英语/[子主题名]/主题总览.md`。
- `deep` 模式默认保存为 `docs/learn/英语/[子主题名]/` 下的多篇结构化文档。
- 输出的 Markdown 文件名必须使用中文，不使用英文语义文件名。
- 文件名可以包含数字前缀以表达学习顺序，如 `00-学习地图.md`、`01-背景含义与核心规则.md`。
- 图示默认优先使用 Mermaid，尤其适用于语法结构图、时态对比图、表达关系图、学习路径图和复习时间线。
- 当 Mermaid 难以表达口型示意、音标发音部位图、教材截图或权威语法图表时，可以从网络抓取图片辅助讲解。
- 网络图片优先选择权威词典、官方教材平台、语言学习机构、大学课程资料或公开教育资源中的图片。
- 使用网络图片时，必须在文档中标注来源链接、图片用途，并简要说明该图片帮助理解什么。
- 对来源不明、版权不清晰、内容失真或营销性质过强的图片，不要使用；此时退回 Mermaid 或文字说明。

## 通用写作要求

每篇文档都应尽量包含：

- 一句话理解
- 这个知识点解决什么表达问题
- 核心规则或核心意义
- 常见场景
- 正确例句和错误例句
- 常见误区
- 练习题

不要把英语学习写成纯规则罗列。必须补充真实表达语境。

## 英语领域质量标准

生成内容时必须做到：

- 先讲“这个表达在现实中怎么用”，再讲规则。
- 例句优先自然、常用、可复用，避免生硬翻译腔。
- 对词汇主题，必须补充词义边界、搭配和语感差异。
- 对语法主题，必须补充“什么时候会自然地用到它”。
- 对阅读、听力、口语、写作主题，必须补充训练方法和纠错路径。

## 结尾要求

结尾固定给出：

- 这次学习最值得记住的 3 句话
- 适合马上练习的 1~3 个任务
- 下一步建议：继续学什么表达、做什么输入、怎么安排复习

如果当前输出的是 `领域学习地图.md`，则把结尾改为：

- 建议先学的 1~3 个子主题
- 每个子主题适合的学习目标
- 等待用户选择下一步要展开的主题
