# Feature 规格说明：图集管理

**Epic**：EPIC-004 - Android 端相册 App 一期
**Feature 类型**：Product Feature
**Feature ID**：FEAT-002
**Feature Version**：v0.1.3
**EPIC 分支**：`epic/EPIC-004-android-gallery`
**Feature 目录**：`specs/epics/EPIC-004-android-gallery/features/FEAT-002-album-management/`
**创建时间**：2026-02-08
**状态**：草稿
**输入**：用户描述：`"图集管理：显示媒体库图集列表，支持新增图集、删除用户新增的图集、给图集添加照片或移出照片，按图集浏览。"`

## 背景与价值 *（必填）*

- **背景**：用户需要按图集维度整理与浏览照片（如旅行、项目、人物等），与时间轴并列作为浏览维度。
- **目标**：提供媒体库图集列表的展示与管理能力，支持新增/删除用户图集、向图集添加或移出照片，按图集浏览内容，并支持按媒体类型（如图片、视频、GIF、实况照片、杜比视频等）查看图集内内容。
- **价值**：独立的产品能力，可与时间轴并列作为浏览维度，逻辑边界清晰。
- **范围（In Scope）**：显示媒体库图集列表（系统/媒体库图集与用户自建图集）；新增图集；删除用户新增的图集（仅用户自建图集可删，系统/媒体库图集不提供删除）；给图集添加照片或移出照片；按图集维度查看照片列表；**按媒体类型查看图集内容**（如图片、视频、GIF、实况照片、杜比视频等）；可选重命名用户自建图集。
- **范围外（Out of Scope）**：云端图集同步、图集分享、自动分类（如人脸/地点）；删除系统/媒体库图集。

## 依赖关系 *（必填）*

- **上游依赖**：时间轴列表浏览（需有照片列表与数据模型）；Android 媒体库与存储权限。
- **下游影响**：搜索 Feature 依赖图集维度条件；用户可自图集进入大图。
- **外部依赖故障模式**：媒体库图集不可用或权限变更时，需明确提示或降级，不崩溃。

## 验收与场景 *（必填）*

### 核心用户旅程

#### 旅程 1 - 查看图集并管理内容

- **描述**：用户查看媒体库图集列表，新增一个图集，从时间轴或列表中将照片加入该图集，或从图集中移出照片，按图集浏览内容；对用户自建图集可删除。
- **成功信号**：用户能完成图集列表查看、新增/删除用户图集、添加/移出照片，且数据一致。
- **验收场景**：
  1. **前提** 已有时轴列表与媒体库访问，**当** 用户进入图集入口，**则** 展示媒体库图集列表（系统图集与用户自建图集）。
  2. **前提** 在图集列表页，**当** 用户执行新增图集，**则** 创建用户图集并可在列表中看到。
  3. **前提** 存在用户自建图集，**当** 用户执行删除，**则** 仅用户自建图集可被删除，系统/媒体库图集不提供删除。
  4. **前提** 某图集已打开，**当** 用户添加照片或移出照片，**则** 图集内容更新且与媒体库一致。
  5. **前提** 在图集列表或图集内列表，**当** 用户点击某张照片，**则** 可进入大图（由大图浏览 Feature 提供）。
  6. **前提** 某图集已打开，**当** 用户选择按媒体类型查看（如图片、视频、GIF、实况照片、杜比视频等），**则** 列表仅展示该类型媒体，并可从结果进入大图。

### 媒体类型查看规范（必填）

- 图集内必须支持**按媒体类型筛选/查看**，使用户能只看某一类媒体。至少支持的类型包括（可根据系统/媒体库能力扩展）：
  - **图片**：静态图片（JPEG、PNG、WebP、HEIC、BMP、TIFF、ICO 等，不含 GIF/实况图）。
  - **视频**：常规视频（如 MP4、MOV 等）。
  - **GIF**：动图。
  - **实况照片**：Live Photo 等实况图。
  - **杜比视频**：Dolby Vision / HDR 等杜比相关视频（若设备与媒体库支持）。
- 展示方式可为：图集内提供类型筛选项（如 Tab/筛选器），选择后列表仅显示该类型；或系统/媒体库提供的「按类型」图集可直接进入查看。
- 按类型查看后的列表仍支持点击进入大图（由大图浏览 Feature 提供）。

### 边界与异常场景（必填）

- 无用户图集时删除入口不展示或禁用；系统图集无删除能力。
- 媒体库图集被系统删除或不可用 → 列表更新或展示提示，不崩溃。
- 添加/移出照片与时间轴列表数据一致性 → 复用同一数据抽象，变更可反映到列表与搜索。

## FR / NFR *（必填）*

### FR（Functional Requirements）

- **FR-001**：系统必须展示媒体库图集列表，包含系统/媒体库图集与用户自建图集。
- **FR-002**：用户必须能够新增图集（用户自建图集）。
- **FR-003**：用户必须能够删除用户新增的图集；系统/媒体库图集不提供删除。
- **FR-004**：用户必须能够向图集添加照片或从图集中移出照片。
- **FR-005**：用户必须能够按图集维度查看照片列表，并可从图集内进入大图。
- **FR-006**：用户必须能够按媒体类型查看图集内容，至少支持按「图片」「视频」「GIF」「实况照片」「杜比视频」（或设备/媒体库支持的同类型）等类型筛选或切换查看，筛选后列表仅展示该类型媒体，并可从结果进入大图。

### NFR（Non-Functional Requirements）

#### 性能（Performance）

- **NFR-PERF-001**：图集列表与图集内照片列表加载与滚动流畅；缩图即滑即现无白块（与 EPIC-NFR-PERF-002 对齐）。

#### 功耗（Power）

- **NFR-POWER-001**：图集浏览与增删操作不导致异常功耗（见 plan 功耗评估，可于 ST-003/ST-004 验证中纳入）。

#### 内存（Memory）

- **NFR-MEM-001**：图集列表与图集内列表内存占用可控（见 plan 内存评估，可于 ST-003/ST-004 验证中纳入）。

#### 安全与隐私（Security/Privacy）

- **NFR-SEC-001**：仅访问用户授权的存储与媒体库，遵守 Android 存储与隐私规范（对齐 EPIC-NFR-SEC-001）。

#### 可观测性（Observability）

- **NFR-OBS-001**：本期可不实现埋点；若后续引入需统一事件口径（对齐 EPIC-NFR-OBS-001）。

#### 可靠性（Reliability）

- **NFR-REL-001**：图集数据与媒体库一致；增删操作失败时给出明确提示，不静默失败。

## 验收标准（Feature Level）*（必填）*

- **AC-001**：用户能查看媒体库图集列表（含系统与用户图集）（FR-001）。
- **AC-002**：用户能新增图集并能删除自己创建的图集，系统图集不可删（FR-002, FR-003）。
- **AC-003**：用户能向图集添加照片或从图集中移出照片，数据一致（FR-004）。
- **AC-004**：用户能按图集浏览照片并从图集进入大图（FR-005）。
- **AC-005**：用户能在图集内按媒体类型（如图片、视频、GIF、实况照片、杜比视频等）筛选或切换查看，仅显示该类型媒体，并可从结果进入大图（FR-006）。
- **AC-006**：图集列表与图集内列表缩图即滑即现无白块（NFR-PERF-001）；增删失败有明确提示（NFR-REL-001）。

## 核心实体（如涉及数据则必填）

- **图集（Album）**：媒体库图集或用户自建图集，含标识、名称、来源（系统/用户）、包含的媒体项引用。
- **媒体项**：与时间轴列表浏览共用同一数据抽象（来自 FEAT-001），含类型信息（图片、视频、GIF、实况照片、杜比视频等），用于「添加/移出照片」及「按媒体类型查看」的粒度。

## 假设与约束 *（必填）*

- **假设**：时间轴列表浏览 Feature 已提供照片列表与数据模型；大图浏览由大图浏览 Feature 提供；用户理解「用户图集」与「系统图集」的差异。
- **约束**：仅操作用户授权范围内的媒体库与图集；不删除系统/媒体库图集；Android 10+（API 29+）。
