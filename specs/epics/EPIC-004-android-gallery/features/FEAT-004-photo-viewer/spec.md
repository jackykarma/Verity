# Feature 规格说明：大图浏览

**Epic**：EPIC-004 - Android 端相册 App 一期
**Feature 类型**：Product Feature
**Feature ID**：FEAT-004
**Feature Version**：v0.1.0
**EPIC 分支**：`epic/EPIC-004-android-gallery`
**Feature 目录**：`specs/epics/EPIC-004-android-gallery/features/FEAT-004-photo-viewer/`
**创建时间**：2026-02-08
**状态**：草稿
**输入**：用户描述：`"大图浏览：缩图轴快速切换大图预览，支持图片、实况图与视频，缩放与滑动切换，从时间轴列表或搜索结果进入并保持上下文。"`

## 背景与价值 *（必填）*

- **背景**：用户从时间轴列表或搜索结果进入后，需要流畅查看大图、实况图与视频，并能在多张之间快速切换。
- **目标**：提供缩图轴、大图预览、多格式支持（图片/实况图/视频）、缩放与滑动切换，从列表或搜索进入并保持上下文。
- **价值**：核心查看体验，与列表/搜索解耦便于单独优化性能与内存。
- **范围（In Scope）**：缩图轴（通过缩图轴快速浏览并切换当前大图预览）；单张/多张大图预览，支持图片、实况图与视频（实况图与视频在预览中可正常播放）；**图片格式**：JPEG、PNG、GIF、WebP、HEIC、BMP、TIFF、ICO；**视频格式**：MP4、MOV、AVI、MKV、WebM、3GP、M4V；缩放（pinch-to-zoom）、左右滑动切换上一张/下一张；从时间轴列表或搜索结果进入并保持上下文（当前索引/列表源）。
- **范围外（Out of Scope）**：编辑、滤镜、裁剪、分享到外部、幻灯片播放。

## 依赖关系 *（必填）*

- **上游依赖**：时间轴列表浏览、搜索（作为入口与上下文来源）；Android 媒体库与存储权限。
- **下游影响**：无其他业务 Feature 依赖本 Feature；列表与图集、搜索提供进入本 Feature 的入口与上下文。
- **外部依赖故障模式**：媒体文件损坏或格式不支持时，需明确提示或占位，不崩溃。

## 验收与场景 *（必填）*

### 核心用户旅程

#### 旅程 1 - 从列表进入大图并滑动浏览

- **描述**：用户从时间轴列表或搜索结果点击某张照片，进入大图预览；通过缩图轴快速定位到另一张，通过左右滑动切换上一张/下一张，支持缩放；若为实况图或视频则可正常播放。
- **成功信号**：用户能流畅查看上述格式的图片（含 GIF）、实况图与视频，进入无黑图、滑动丝滑，内存与流畅度可接受。
- **验收场景**：
  1. **前提** 从时间轴或搜索进入，**当** 用户点击某张照片，**则** 大图以自然过渡方式呈现，无黑图阶段。
  2. **前提** 处于大图预览，**当** 用户左右滑动，**则** 上一张/下一张丝滑切换，无黑图、无可见加载过程。
  3. **前提** 处于大图预览，**当** 用户使用缩图轴，**则** 可快速定位并切换当前预览。
  4. **前提** 当前为图片/实况图/视频，**则** 支持约定格式的预览与播放（图片含 GIF；视频可播放）。
  5. **前提** 处于大图预览，**当** 用户双指缩放，**则** 支持 pinch-to-zoom。

### 边界与异常场景（必填）

- 文件损坏或格式不支持 → 展示占位或明确提示，不崩溃。
- 从列表进入时上下文（当前索引/列表源）保持，便于滑动时顺序正确。
- 大图浏览时内存占用可控，不因浏览大量图片导致 OOM 或系统杀进程（EPIC-NFR-MEM-001）。

## FR / NFR *（必填）*

### FR（Functional Requirements）

- **FR-001**：用户必须能够通过缩图轴快速浏览并切换当前大图预览。
- **FR-002**：系统必须支持单张/多张大图预览，支持图片、实况图与视频；实况图与视频在预览中可正常播放。
- **FR-003**：系统必须支持以下图片格式的预览：JPEG、PNG、GIF、WebP、HEIC、BMP、TIFF、ICO。
- **FR-004**：系统必须支持以下视频格式的预览与播放：MP4、MOV、AVI、MKV、WebM、3GP、M4V。
- **FR-005**：用户必须能够通过缩放（pinch-to-zoom）与左右滑动切换上一张/下一张。
- **FR-006**：从时间轴列表或搜索结果进入时，必须保持上下文（当前索引/列表源），滑动顺序与入口列表一致。

### NFR（Non-Functional Requirements）

#### 性能（Performance）

- **NFR-PERF-001**：从缩图进入大图需自然过渡，无黑图阶段（不出现先黑屏再出图）（对齐 EPIC-NFR-PERF-003）。
- **NFR-PERF-002**：大图左右滑动时不得出现黑图、不得出现可见的图片加载过程，需丝滑浏览体验（滑到即见、无空白/黑屏/加载中态）（对齐 EPIC-NFR-PERF-003）。

#### 功耗（Power）

- **NFR-POWER-001**：大图与视频播放不导致异常功耗。[需在 Plan 阶段细化]

#### 内存（Memory）

- **NFR-MEM-001**：大图浏览时内存占用可控，不因浏览大量图片导致 OOM 或系统杀进程（对齐 EPIC-NFR-MEM-001）。

#### 安全与隐私（Security/Privacy）

- **NFR-SEC-001**：仅访问用户授权的存储与媒体库，遵守 Android 存储与隐私规范（对齐 EPIC-NFR-SEC-001）。

#### 可观测性（Observability）

- **NFR-OBS-001**：本期可不实现埋点；若后续引入需统一事件口径（对齐 EPIC-NFR-OBS-001）。

#### 可靠性（Reliability）

- **NFR-REL-001**：文件损坏或格式不支持时，展示占位或明确提示，不崩溃。

## 验收标准（Feature Level）*（必填）*

- **AC-001**：用户能从列表或搜索进入大图，进入时自然过渡、无黑图（FR-006, NFR-PERF-001）。
- **AC-002**：用户能通过缩图轴快速定位并切换当前预览（FR-001）。
- **AC-003**：用户能左右滑动切换上一张/下一张，丝滑无黑图、无可见加载过程（FR-005, NFR-PERF-002）。
- **AC-004**：约定图片格式（JPEG、PNG、GIF、WebP、HEIC、BMP、TIFF、ICO）与视频格式（MP4、MOV、AVI、MKV、WebM、3GP、M4V）可正常预览/播放（FR-002, FR-003, FR-004）。
- **AC-005**：用户能对大图进行 pinch-to-zoom（FR-005）。
- **AC-006**：大图浏览时内存可控，无 OOM 或进程被杀（NFR-MEM-001）；异常文件有提示不崩溃（NFR-REL-001）。

## 核心实体（如涉及数据则必填）

- **大图上下文**：当前预览索引、来源列表（时间轴/图集/搜索结果）及列表标识，用于保持滑动顺序与返回。
- **媒体项**：与时间轴/搜索共用的媒体项引用，含 URI、格式、类型（图片/实况图/视频）。

## 假设与约束 *（必填）*

- **假设**：时间轴列表与搜索提供进入本 Feature 的入口与列表上下文；设备具备解码上述格式的能力（或可降级提示）。
- **约束**：仅访问用户授权媒体库；Android 10+（API 29+）；大图加载与缓存策略由本 Feature 统一负责，列表仅提供 URI/ID 等上下文。
