# EPIC-004 Android 相册 UI 设计

本目录存放 Android 端相册 App（EPIC-004）的 UI 设计稿，**每屏严格对照各自 Feature 的 spec**，风格对齐 Apple Music：深色主题、毛玻璃质感、自然过渡动效。

## 设计文件

- **gallery-uidesign.pen**：主设计稿（在 Pencil 中打开）
  - 四屏：时间轴列表 (FEAT-001)、图集管理 (FEAT-002)、搜索 (FEAT-003)、大图浏览 (FEAT-004)
  - 画布内含「Apple Music 风格规范」说明卡片
- 若本目录下尚无 `gallery-app.pen`，请按 **如何将设计稿保存到本目录.md** 操作，在 Pencil 中另存为到本目录或从其他位置复制到此

## 设计规范摘要

| 项目     | 说明 |
|----------|------|
| **毛玻璃** | 顶栏、底栏使用 `rgba(58,58,65,0.88)` + 白色高光边，实现时叠加 Backdrop Blur 才有真实质感 |
| **日/月/年** | 三个 Tab 并排显示（日选中蓝底、月/年灰底），切换即改列数 |
| **缩略图** | 实现用 `scaleType=centerCrop` 保证完整显示、避免拉伸变形 |
| **过渡动效** | 页面切换、列表进入大图使用共享元素 + 淡入淡出，时长 300–350ms |
| **圆角** | 卡片 12px、按钮 8–16px、屏幕外框 24px |
| **主色** | 背景 `#0A0A0C` / `#1C1C1E`，强调色 `#0A84FF` |

## 屏幕与 Feature Spec 对照（按 spec 设计）

### 时间轴列表 — FEAT-001-timeline-list

| Spec 要点 | UI 体现 |
|-----------|---------|
| 日/月/年视图切换 | 顶栏下分段控件「日」「月」「年」 |
| 列数约定：日 3/6 列、月 15 列、年 32 列 | 文案提示「日3/6列 · 月15列 · 年32列」 |
| 双指无极缩放 | 交互说明，列数随缩放在约定范围内变化 |
| 快滑条 thumb 在列表右侧，左侧显示当前行日期 | 右侧快滑条 + 左侧日期气泡（年月日，与视图维度一致） |
| 筛选（仅照片、按类型等） | 顶栏筛选图标 + 文案「筛选: 仅照片/按类型」 |
| 日期显示：今天、昨天、完整年月日 | 分组条「今天 · 2026年2月8日」「昨天 · 2026年2月7日」 |
| 点击进入大图 | 网格项可点击，由大图浏览承接 |
| 空状态/无权限 | 媒体库为空或无权限时展示空状态或引导授权（实现时） |

### 图集管理 — FEAT-002-album-management

| Spec 要点 | UI 体现 |
|-----------|---------|
| 媒体库图集列表（系统 + 用户自建） | 列表项展示「最近项目」「收藏」「我的旅行」等，副标题标「系统图集」/「用户图集」 |
| 新增图集 | 顶栏「+」按钮 |
| 仅用户自建图集可删，系统图集不提供删除 | 用户图集副标题「可删」，系统图集无删除入口 |
| 按媒体类型查看（视频、GIF、实况照片、杜比视频） | 顶栏下类型筛选项「全部」「视频」「GIF」「实况照片」「杜比视频」 |
| 添加/移出照片、可选重命名 | 进入图集内后操作（图集内页或长按菜单，实现时） |
| 从图集进入大图 | 点击图集内照片进入大图（由 FEAT-004 承接） |

### 搜索 — FEAT-003-search

| Spec 要点 | UI 体现 |
|-----------|---------|
| 自然语言检索 | 搜索框占位「自然语言或关键词、日期、图集搜索…」 |
| 按关键词、日期范围、图集等条件 | 筛选 Chip「关键词」「日期」「图集」 |
| 展示搜索结果列表 | 结果网格，缩图即滑即现 |
| 从结果进入大图 | 点击结果项进入大图 |
| 无匹配结果 / 搜索失败 | 空状态说明「无匹配结果时显示空状态提示（FEAT-003 AC-005）」 |

### 大图浏览 — FEAT-004-photo-viewer

| Spec 要点 | UI 体现 |
|-----------|---------|
| 缩图轴快速切换当前大图预览 | 底部缩图轴，当前项高亮边框 |
| 单张/多张大图预览，图片/实况图/视频 | 中央大图区域 + 文案「支持图片/实况图/视频 · 缩放/滑动切换」 |
| 支持格式：JPEG、PNG、GIF、WebP、HEIC…；视频 MP4、MOV… | 实现时按 spec 支持，UI 用文案概括 |
| 缩放（pinch-to-zoom）、左右滑动切换 | 交互说明在顶部或缩图轴旁 |
| 从时间轴/搜索结果进入并保持上下文 | 顶部显示「来自时间轴 · 2026年2月8日 · 1/24」 |
| 进入无黑图、滑动丝滑 | NFR，实现时保证 |

## 使用方式

1. 在 Pencil 中打开 `gallery-uidesign.pen`（或通过 Cursor 的 Pencil MCP 打开 `specs/epics/EPIC-004-android-gallery/design/gallery-app.pen`）。
2. 实现时在 Android 端使用：
   - 毛玻璃：`RenderEffect.createBlurEffect` + 半透明背景（API 31+）或第三方 Blur 方案。
   - 过渡：共享元素过渡 + `fade`，时长 300–350ms。
3. **每屏实现前请对照上述表格与对应 Feature 的 `spec.md`**，确保 FR/AC 均有 UI 或交互对应。
