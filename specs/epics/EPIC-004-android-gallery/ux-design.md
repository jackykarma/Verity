## 信息架构

### 跨 Feature 导航与流程

- **主导航**：底部 Tab 或主入口切换，支持「时间轴」「图集」双维度浏览；搜索作为全局入口（顶栏或 Tab）可覆盖时间轴/图集结果；大图浏览为全屏叠加层，从时间轴、图集、搜索结果均可进入。
- **跨 Feature 流程**：
  1. **时间轴 → 大图**：点击列表项进入大图预览，保持上下文（当前索引/列表源）。
  2. **图集 → 大图**：点击图集内照片进入大图，上下文来源为图集。
  3. **搜索 → 大图**：从搜索结果点击进入大图，保持结果列表上下文。
  4. **时间轴 → 图集**：从时间轴将照片加入图集（选图面板多选）或从图集移出照片；图集列表与时间轴并列入口。
  5. **端到端路径**：按时间浏览 → 加入图集 → 搜索到某张图 → 大图查看（3 分钟内完成）。

## 交互说明

### 核心流程的交互规则

| 操作 | 触发方式 | 反馈 | 步骤 |
|------|----------|------|------|
| 切换日/月/年视图 | 顶栏分段控件点击 | 列表列数立即变化（日 3/6、月 15、年 32），选中项粉底高亮 | 单步 |
| 双指无极缩放 | 列表上双指 pinch | 网格密度连续变化，列数在约定范围内 | 单步 |
| 快滑条定位 | 拖拽列表右侧 thumb | 左侧显示当前行对应日期（年月日，与视图一致） | 单步 |
| 筛选 | 顶栏筛选图标 | 可选「仅照片」「按类型」等 | 单步 |
| 进入大图 | 点击缩略图 | 共享元素过渡 + 淡入，300–350ms，无黑图 | 单步 |
| 大图左右滑动 | 左右滑动 | 丝滑切换，滑到即见，无黑图/无加载中态 | 单步 |
| 缩图轴切换 | 底部缩图轴点击/滑动 | 焦点项始终居中，当前项高亮边框 | 单步 |
| 新建图集 | 图集列表顶栏「+」 | 弹出创建图集弹窗 | 输入名称 → 创建 |
| 添加照片到图集 | 图集内「添加」 | 选图面板多选网格，确认添加 N 张 | 多选 → 添加 |

### 状态定义

| 状态 | 说明 | 表现 |
|------|------|------|
| **loading** | 列表/搜索/大图加载中 | 骨架屏或占位，避免白块；大图禁止黑屏 |
| **空态** | 媒体库为空、无匹配结果、无权限 | 明确文案 + 引导（如授权按钮） |
| **错误态** | 媒体库不可用、搜索失败、文件损坏 | 内联提示或 Toast，不崩溃 |
| **成功态** | 数据加载完成、操作成功 | 列表正常展示；创建/添加成功可 Toast 或内联 |

### 反馈方式

- **Toast**：操作成功（如「已添加 5 张照片到图集」）、轻量提示。
- **Dialog**：创建图集（输入框 + 取消/创建）、删除确认（如有）。
- **内联提示**：空态、错误态文案与引导。
- **动效**：页面切换与列表进入大图使用共享元素 + 淡入淡出，300–350ms；缩图轴滑动时焦点项居中。

### 异常与边界

| 场景 | 交互对策 |
|------|----------|
| 无权限 | 空态展示 + 引导授权按钮，不崩溃 |
| 媒体库为空 | 空态文案「暂无照片」 |
| 无匹配结果 | 搜索空态「无匹配结果」 |
| 自然语言歧义 | 降级为结构化条件或提示用户细化 |
| 文件损坏/格式不支持 | 占位或明确提示，不崩溃 |
| 增删操作失败 | 明确 Toast 或内联提示，不静默失败 |

## 视觉规范

### 布局

- **栅格**：屏幕外框约 24px；卡片、列表项间距按 8px 倍数。
- **留白**：分组标题与列表、顶栏与内容间保持呼吸感。
- **层级**：顶栏、底栏（大图缩图轴）使用毛玻璃，内容区深色背景。

### 组件

| 组件 | 约定 |
|------|------|
| **顶栏** | 毛玻璃 `rgba(28,28,30,0.72~0.75)` + 细白边，Backdrop Blur |
| **分段控件（日/月/年）** | 选中粉底 `#FA243C`，未选灰底 |
| **快滑条** | thumb 在列表右侧，左侧日期气泡（年月日，与视图维度一致） |
| **缩略图** | `scaleType=centerCrop`，避免拉伸变形 |
| **卡片** | 圆角 12px |
| **按钮** | 圆角 8–16px |
| **筛选 Chip** | 关键词、日期、图集等条件 |

### 动效/过渡

- **入场/退场**：共享元素过渡 + 淡入淡出，时长 300–350ms。
- **大图进入**：从缩图进入大图需自然过渡，无黑图阶段。
- **大图滑动**：左右滑动丝滑，滑到即见，无空白/黑屏/加载中态。
- **缩图轴**：焦点项始终居中，滑动时自动 scroll 使 focus item 稳定在屏幕中央。

### 响应与适配

- **断点**：手机与平板均支持；平板可考虑双栏或更大网格。
- **字体/缩放**：遵循系统字体缩放；日期格式遵循当前语言/区域。

### 色彩与风格（Apple Music 风格）

| 项目 | 说明 |
|------|------|
| **背景** | `#0A0A0C` / `#1C1C1E` |
| **强调色** | `#FA243C`（Apple Music 粉） |
| **毛玻璃** | 顶栏、底栏半透明 + Backdrop Blur |
| **圆角** | 卡片 12px、按钮 8–16px、屏幕外框 24px |
