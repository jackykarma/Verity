## FR / NFR *（必填）*

### FR（Functional Requirements）

- **FR-001**：用户打开页面后，可看到横版游戏画面、卡比角色、当前分数与操作说明。
- **FR-002**：用户可通过方向键（左/右）或 A/D 控制卡比水平移动；通过空格或上方向键/W 跳跃。
- **FR-003**：卡比受重力影响下落，站在平台/地面上时不穿透；离开平台边缘后自然下落。
- **FR-004**：游戏镜头随卡比水平移动，使用户始终能看到角色与前方关卡。
- **FR-005**：关卡中散布可收集星星，卡比触碰后星星消失，分数增加。
- **FR-006**：卡比触碰关卡终点旗杆后，游戏判定通关，显示通关界面与最终分数。
- **FR-007**：卡比掉出关卡底部（死亡区）时，游戏结束，显示失败界面与分数，并提供重新开始入口。
- **FR-008**：用户可暂停与继续游戏；暂停时卡比与关卡逻辑停止，界面显示暂停状态。
- **FR-009**：游戏结束或通关后，用户可重新开始，分数归零，卡比与收集物重置为初始状态。

### NFR（Non-Functional Requirements）

- **NFR-PERF-001**：首屏加载至可操控卡比 ≤ 3 秒（本地 dev 环境，常规桌面浏览器）。
- **NFR-PERF-002**：游戏运行帧率稳定，肉眼无明显卡顿（目标 ≥ 30 FPS）。
- **NFR-MEM-001**：单页内存占用增量 ≤ 80 MB（游戏运行期间）。
- **NFR-SEC-001**：不收集用户个人信息；无外部网络请求（静态资源除外）。
- **NFR-OBS-001**：N/A（无埋点要求）。
- **NFR-REL-001**：浏览器标签页切换后再返回，游戏状态保持；刷新页面则重置。

## AC（验收标准）*（必填）*

- **AC-001**：打开页面 3 秒内可见关卡与卡比，可立即移动（FR-001, NFR-PERF-001）。
- **AC-002**：左右移动与跳跃操作响应正确，卡比不会穿墙/穿平台（FR-002, FR-003）。
- **AC-003**：镜头跟随卡比，前方平台可见（FR-004）。
- **AC-004**：收集星星后分数增加、星星消失（FR-005）。
- **AC-005**：触碰旗杆后显示通关界面（FR-006）。
- **AC-006**：掉出底部后显示失败界面，可重新开始（FR-007, FR-009）。
- **AC-007**：按空格或暂停按钮可暂停/继续（FR-008）。
- **AC-008**：`npm run build` 构建成功，`npm test` 核心逻辑测试通过。
