**EPIC ID**：EPIC-007
**EPIC Version**：v0.1.0
**创建时间**：2026-06-28

**输入**：`"在当前分支下，设计与开发一款星之卡比的跳跃小游戏，类似古老的马力欧。但是角色用星之卡比的卡比。"`

## 背景、目标与价值 *（必填）*

- **背景**：用户希望在浏览器中体验经典横版跳跃闯关玩法，以星之卡比中的卡比为主角，唤起复古平台动作游戏的乐趣。
- **目标**：交付一个可在现代浏览器中打开、即开即玩的卡比主题横版跳跃网页游戏。
- **价值**：提供轻量、零安装的休闲娱乐入口；展示 Verity 仓库 Web 前端游戏能力。
- **产品竞争力**：经典横版跳跃玩法 + 卡比角色辨识度；单关卡可重复挑战。
- **技术竞争力**：纯前端、无后端依赖；可静态部署。
- **成功标准（EPIC Level）**：用户在浏览器打开页面后 3 秒内可操控卡比移动与跳跃；完成从起点到终点旗杆的完整闯关流程。

## 范围 *（必填）*

- **In Scope**：横版侧滚关卡；卡比左右移动与跳跃；平台与重力物理；收集星星计分；终点旗杆通关；掉落失败与重新开始；暂停/继续。
- **Out of Scope**：用户账号与登录；多关卡选关；Boss 战；联机对战；移动端原生 App；后端服务；官方任天堂素材授权（使用原创卡比风格图形）。
- **上项范围**：
  - 地区：全球（Web）
  - 销售渠道：Web 浏览器访问
  - 设备类型：桌面浏览器为主，移动端浏览器基本可用
  - 机型定位：通用
  - OS 版本：现代浏览器（近 2 年主流版本）
  - 保密等级：公开
- **上项节奏**：一次性交付 MVP（单关卡）

## 约束与假设 *（必填）*

- **约束**：纯前端实现；须可在本地开发与静态构建后部署；遵循 Verity 仓库 apps/ 子项目组织方式；在当前 Git 分支 `epic/EPIC-006-snake-game-web` 上创建 EPIC 目录（不新建 epic 分支）。
- **假设**：用户具备键盘能力；无网络时本地打开构建产物仍可游玩（离线静态资源）；卡比视觉为原创简化风格，非官方素材。

### Feature 边界说明（每个 Feature 必填）

#### FEAT-001 - 卡比跳跃网页游戏

- **类型**：Product
- **用户价值**：用户在浏览器中操控卡比完成横版跳跃闯关，获得收集星星的分数反馈与通关/重开能力。
- **目标**：交付完整可玩的单关卡卡比跳跃网页应用。
- **范围（In）**：横版关卡渲染与镜头跟随；卡比移动/跳跃/重力；平台碰撞；星星收集计分；终点旗杆通关判定；掉落失败；暂停/继续；游戏结束/通关与重新开始；基础 UI（标题、分数、操作说明）。
