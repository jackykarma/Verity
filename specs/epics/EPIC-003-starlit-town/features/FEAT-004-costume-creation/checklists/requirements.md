# 需求质量检查清单：装扮与创造系统

**用途**：FEAT-004 需求规格的完整性、可测试性与一致性检查
**创建时间**：2025-02-05
**功能**：[spec.md](../spec.md)

## FR 可测试性

- [ ] CHK001 FR-001：换装（发型/裙子/鞋子/背包）可选且即时反馈，可手工验证
- [ ] CHK002 FR-002：风格标签可选且可展示，无属性数值，可手工验证
- [ ] CHK003 FR-003：房间墙纸可更换且可持久化，可手工验证
- [ ] CHK004 FR-004：宠物可命名且可见称呼反馈并可持久化，可手工验证
- [ ] CHK005 FR-005：贴纸式裙子设计可完成并应用至角色，可手工验证
- [ ] CHK006 FR-006：装扮/墙纸/宠物名/裙子设计状态可持久化并在重进后恢复，可手工验证

## NFR 量化与验收

- [ ] CHK007 NFR-PERF-001：换装/墙纸/贴纸操作响应有明确阈值（≤500ms），可工具测量
- [ ] CHK008 NFR-PERF-001：素材加载不阻塞主线程，可工具或手工验证
- [ ] CHK009 NFR-MEM-001：装扮与创造相关内存增量可控，可工具测量
- [ ] CHK010 NFR-SEC-001：宠物命名等内容有合规与过滤说明，可审查验证
- [ ] CHK011 NFR-OBS-001：换装/墙纸/宠物命名/裙子设计保存有日志或埋点，可审查验证
- [ ] CHK012 NFR-REL-001：存储异常有提示或当次会话降级策略，可模拟验证

## AC 与 FR/NFR 追溯

- [ ] CHK013 AC-001 ~ AC-007 均引用 FR 或 NFR ID，无遗漏
- [ ] CHK014 每条 FR 至少被一个 AC 覆盖
- [ ] CHK015 关键 NFR 至少被一个 AC 覆盖

## 边界与异常

- [ ] CHK016 未选某品类（如背包）有定义及期望行为
- [ ] CHK017 宠物命名为空或违规有定义及期望行为
- [ ] CHK018 贴纸/资源加载失败有降级或提示
- [ ] CHK019 本地存储不可用场景有定义及期望行为
