# 需求质量检查清单：AI 小故事（日记式）

**用途**：FEAT-006 需求规格的完整性、可测试性与一致性检查
**创建时间**：2025-02-05
**功能**：[spec.md](../spec.md)

## FR 可测试性

- [ ] CHK001 FR-001：晚上可进入“今天的故事”视图，可手工验证
- [ ] CHK002 FR-002：当日事件数据可作为故事输入，可数据或集成验证
- [ ] CHK003 FR-003：可展示简短、日记式、轻叙事故事，可手工验证
- [ ] CHK004 FR-004：AI 不可用/超时时降级为模板故事，可模拟验证
- [ ] CHK005 FR-005：故事内容符合儿童合规，可审查验证

## NFR 量化与验收

- [ ] CHK006 NFR-PERF-001：入口响应与 AI 超时阈值有定义，可工具或模拟测量
- [ ] CHK007 NFR-MEM-001：故事与事件快照内存有约束，可 Plan 阶段细化
- [ ] CHK008 NFR-SEC-001：内容安全与合规策略有说明，可审查验证
- [ ] CHK009 NFR-OBS-001：生成成功/降级/失败可观测，可审查验证
- [ ] CHK010 NFR-REL-001：AI 故障时必走模板，可模拟验证

## AC 与 FR/NFR 追溯

- [ ] CHK011 AC-001 ~ AC-006 均引用 FR 或 NFR ID，无遗漏
- [ ] CHK012 每条 FR 至少被一个 AC 覆盖
- [ ] CHK013 关键 NFR 至少被一个 AC 覆盖

## 边界与异常

- [ ] CHK014 当日无活动、AI 内容不合规、保存失败有定义及期望行为
- [ ] CHK015 模板库与降级策略可维护扩展有说明或预留
