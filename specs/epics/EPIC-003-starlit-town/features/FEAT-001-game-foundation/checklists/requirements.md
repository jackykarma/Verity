## FR 可测试性

- [ ] CHK001 FR-001：游戏入口可打开并展示主界面，可手工验证
- [ ] CHK002 FR-002：场景切换功能可用，各地图节点可进入，可手工验证
- [ ] CHK003 FR-003：每日循环三阶段可推进，可手工验证

## NFR 量化与验收

- [ ] CHK006 NFR-PERF-001：首屏加载时间有明确阈值（≤3s），可工具测量
- [ ] CHK007 NFR-PERF-001：场景切换响应有明确阈值（≤500ms），可工具测量
- [ ] CHK008 NFR-MEM-001：内存增量有上限说明，可工具测量
- [ ] CHK009 NFR-SEC-001：无个人敏感信息收集，可审查验证
- [ ] CHK010 NFR-OBS-001：关键操作有日志/观测点，可审查验证
- [ ] CHK011 NFR-REL-001：存储失败有降级策略，可模拟验证
