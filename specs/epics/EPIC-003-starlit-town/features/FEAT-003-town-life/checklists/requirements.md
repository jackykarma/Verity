# 需求质量检查清单：小镇生活系统

**用途**：FEAT-003 需求规格的完整性、可测试性与一致性检查
**创建时间**：2025-02-05
**功能**：[spec.md](../spec.md)

## FR 可测试性

- [ ] CHK001 FR-001：早上选衣服与小心情并可进入白天，可手工验证
- [ ] CHK002 FR-002：家/学校/公园/商店/森林各场景可进入并有内容，可手工验证
- [ ] CHK003 FR-003：各场景典型活动（上课、喂动物、逛商店、森林探索）可完成，可手工验证
- [ ] CHK004 FR-004：白天可触发 2–3 个小事件并有反馈，可手工验证
- [ ] CHK005 FR-005：晚上可进入“今天的故事”总结入口，可手工验证

## NFR 量化与验收

- [ ] CHK006 NFR-PERF-001：场景内响应与事件展示有阈值或描述，可工具或手工测量
- [ ] CHK007 NFR-MEM-001：场景与事件状态内存有约束说明，可 Plan 阶段细化
- [ ] CHK008 NFR-SEC-001：无个人敏感信息、儿童合规，可审查验证
- [ ] CHK009 NFR-OBS-001：关键操作可观测，可审查验证
- [ ] CHK010 NFR-REL-001：状态与存储一致、异常有降级，可模拟验证

## AC 与 FR/NFR 追溯

- [ ] CHK011 AC-001 ~ AC-006 均引用 FR 或 NFR ID，无遗漏
- [ ] CHK012 每条 FR 至少被一个 AC 覆盖
- [ ] CHK013 关键 NFR 至少被一个 AC 覆盖

## 边界与异常

- [ ] CHK014 未完成场景活动即切换、小事件条件不满足有定义及期望行为
- [ ] CHK015 晚上总结入口占位或与 FEAT-006 衔接有说明
