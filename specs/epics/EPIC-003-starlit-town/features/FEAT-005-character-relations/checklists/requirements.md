# 需求质量检查清单：角色关系系统

**用途**：FEAT-005 需求规格的完整性、可测试性与一致性检查
**创建时间**：2025-02-05
**功能**：[spec.md](../spec.md)

## FR 可测试性

- [ ] CHK001 FR-001：用户可与至少一类 NPC 互动，可手工验证
- [ ] CHK002 FR-002：互动可被记录并持久化，可手工或数据验证
- [ ] CHK003 FR-003：再次互动时反馈体现“记得我”且无好感值，可手工验证
- [ ] CHK004 FR-004：不同 NPC 性格与反馈风格可区分，可手工验证
- [ ] CHK005 FR-005：关系与记忆状态可恢复，可手工验证

## NFR 量化与验收

- [ ] CHK006 NFR-PERF-001：互动与反馈响应有阈值，可工具或手工测量
- [ ] CHK007 NFR-MEM-001：关系与记忆数据内存有约束，可 Plan 阶段细化
- [ ] CHK008 NFR-SEC-001：记忆仅存本地、儿童合规，可审查验证
- [ ] CHK009 NFR-OBS-001：关键操作可观测，可审查验证
- [ ] CHK010 NFR-REL-001：存储失败有降级，可模拟验证

## AC 与 FR/NFR 追溯

- [ ] CHK011 AC-001 ~ AC-006 均引用 FR 或 NFR ID，无遗漏
- [ ] CHK012 每条 FR 至少被一个 AC 覆盖
- [ ] CHK013 关键 NFR 至少被一个 AC 覆盖

## 边界与异常

- [ ] CHK014 首次见面、无历史互动、记忆丢失有定义及期望行为
- [ ] CHK015 同一会话多次互动的记忆更新规则有说明或预留 Plan 细化
