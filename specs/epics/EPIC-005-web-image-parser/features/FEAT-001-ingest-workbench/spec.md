## 背景与价值 *（必填）*

| 项 | 内容 |
|---|---|
| 背景 | 用户需先完成文件选择与解析启动，才能进入分区浏览；若入口分散或错误提示不清，会导致排障与学习成本上升。 |
| 目标 | 提供统一的 Web 工作台，完成 JPEG/HEIC 文件接入、校验、解析状态反馈，并导航至格式专属分区浏览能力。 |
| 价值 | 用户在一个界面内完成「选文件 → 确认可解析 → 等待结果 → 进入浏览」，失败时可恢复并重试。 |
| In Scope | 文件选择/拖放接入；类型与大小校验；解析状态（进行中/成功/失败/部分成功）；进入分区浏览的导航框架；重新选文件与放弃当前任务；文件级错误统一提示。 |
| Out of Scope | 各格式分区语义解析（FEAT-002/003）；分区内容呈现（FEAT-004）；账号/历史记录；非 JPEG/HEIC 主文件接入。 |

## FR / NFR *（必填）*

### FR（Functional Requirements）

- **FR-001**：用户**必须**能通过选择本地文件或拖放方式，将 **1** 个文件接入工作台（本期不支持批量多文件同时解析）。
- **FR-002**：系统**必须**在解析开始前校验主文件类型仅为 **JPEG** 或 **HEIC**（含常见扩展名变体，清单在验收附件中冻结）；不符合时**拒绝**解析并说明支持的类型。
- **FR-003**：系统**必须**校验文件大小不超过 **50MB**；超出时拒绝并显示上限值与建议（如压缩或更换样例）。
- **FR-004**：用户**必须**能显式触发解析；触发后系统**必须**展示解析状态：进行中、成功、失败、部分成功（部分成功定义：至少识别出部分分区但存在未解析段，由 FEAT-002/003 回传状态）。
- **FR-005**：解析成功后，系统**必须**将用户引导至「分区浏览」视图框架，并加载对应格式 Feature 的分区树区域（JPEG → FEAT-002；HEIC → FEAT-003）。
- **FR-006**：用户**必须**能在不刷新页面的情况下重新选择文件；重新选择时**必须**终止或放弃当前解析任务并清理上一文件会话状态。
- **FR-007**：解析失败时，系统**必须**给出可理解的失败原因类别（类型不支持、文件过大、文件损坏、解析超时、未知错误），且**必须**提供「重新选择文件」能力，页面仍可用。
- **FR-008**：系统**必须**向用户明确告知：文件仅在当前浏览器会话内处理，不上传至服务端（隐私说明可在首次接入或关于说明中展示，文案由产品冻结）。
- **FR-009**：解析进行中，用户**必须**能取消或放弃当前解析（若取消，状态变为已取消，可重新触发或换文件）。

### NFR（Non-Functional Requirements）

- **NFR-PERF-001**：对 ≤ **20MB** 合规文件，从用户触发解析到工作台收到「可展示分区列表」信号，**P95 ≤ 10 秒**（与 EPIC 一致；分区列表由 FEAT-002/003 产出）。
- **NFR-PERF-002**：文件类型与大小校验结果须在用户完成选择后 **1 秒内** 反馈（P95）。
- **NFR-POWER-001**：**N/A**——Web 浏览器端；解析进行中 CPU 占用不得导致界面完全无响应超过 **3 秒**（用户仍能取消或看到进度提示）。
- **NFR-MEM-001**：工作台壳层（不含格式解析引擎）额外内存占用增量 **≤ 30MB**（相对打开空白页基线，常规办公设备）。
- **NFR-SEC-001**：未经用户明确操作，**不得**将文件内容发送至任何远程地址；**不得**在本地保留用户文件供关闭页面后再次打开（本期无历史记录）；错误信息不含完整文件路径。
- **NFR-OBS-001**：文件级失败**必须**记录失败类型枚举（类型/大小/损坏/超时/取消/未知），供测试对账；不要求第三方埋点（本期）。
- **NFR-REL-001**：连续 **20** 次「选择文件 → 解析 → 成功或明确失败」操作后，工作台仍可用，无必须刷新页面才能恢复的情况。

## AC（验收标准）*（必填）*

- **AC-001**：**100%** 合规 JPEG/HEIC 样例可在工作台完成接入并进入解析成功路径（引用 FR-001、FR-002、FR-004、FR-005）。
- **AC-002**：PNG/MP4 等超范围主文件 **100%** 被拒绝且说明支持类型（引用 FR-002）。
- **AC-003**：**51MB** 样例 **100%** 因大小被拒绝（引用 FR-003）。
- **AC-004**：解析失败样例 **100%** 显示失败类别且可重新选文件（引用 FR-007、NFR-REL-001）。
- **AC-005**：新用户 **90%** 在 **3 分钟**内完成首次「选文件 → 解析成功 → 看到分区浏览框架」（可用性试点，引用 FR-005、NFR-PERF-001）。
- **AC-006**：隐私说明在首次接入或帮助入口可见（引用 FR-008、NFR-SEC-001）。
