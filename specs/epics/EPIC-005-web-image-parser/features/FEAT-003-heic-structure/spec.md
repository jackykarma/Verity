## 解析内容目录 *（必填，验收基准）*

> **说明**：HEIC/HEIF 基于 ISO 基媒体文件格式（容器）+ 图像项/轨道的组合。表中**行业标识**为容器/图像领域通用 box/项类型称呼。  
> **优先级**：**P0**＝GA 必达；**P1**＝完整版必达（**验收覆盖率 ≥ 95%**）；**P2**＝尽力识别。  
> **呈现**列对齐 FEAT-004。

### 目录总规则

- 从**文件级容器**到**元数据项、图像项、辅助项、媒体数据**须形成可展开层级树，不得将整文件扁平化为单节点。
- **图像项**（主图、缩略图、深度图、HDR 增益等）负载类型为「图片」（深度/HDR 等辅助图须标注子类型供 FEAT-004 FR-011）；**视频轨/运动影像**为「视频」；**音频轨**为「音频」；**元数据/属性**为「文本·元数据」。
- **项间引用**（如缩略图指向主图、辅助图指向主图）须在可读呈现中说明关系（P1）。

## FR / NFR *（必填）*

### FR（Functional Requirements）

- **FR-001**：系统**必须**对当前会话中的 HEIC 主文件构建**层级分区列表**，交互能力不低于 FEAT-002（展开/折叠、选中）。
- **FR-002**：系统**必须**按 §解析内容目录 构建容器树：**P0 100%**；**P1 ≥ 95%** 或命中 §已知限制；未知结构归入 PAR-HEIC-099。
- **FR-009**：对 PAR-HEIC-302 运动影像/Live Photo，系统**必须**同时展示关联的**主图项与视频项**，并在 iref（PAR-HEIC-010）可读呈现中说明配对关系。
- **FR-010**：对含 PAR-HEIC-301 视频轨的文件，系统**必须**提供视频播放路径；对 PAR-HEIC-401～404 轨道结构在 P1 阶段至少展示**轨道类型与编码说明**。
- **FR-011**：PAR-HEIC-002 meta 子节点**必须**包含 P0 所列 hdlr、pitm、iinf、iloc、iprp（及 ipco）的可展开子树，不得仅显示 meta 单节点。
- **FR-012**：对 PAR-HEIC-305/306 音频轨，系统**必须**上报负载类型「音频」并供 FEAT-004 播放；在支持环境样例中 **≥ 95%** 可连续播放 **≥ 3 秒**。
- **FR-013**：对 PAR-HEIC-110/111/113 及 PAR-HEIC-C06 深度/增益辅助图，系统**必须**在可解码时提供图片预览引用（含子类型：深度图/HDR 增益/透明度）；不可解码时走 LIM-HEIC-06。
- **FR-014**：对 PAR-HEIC-201 Exif 项，系统**必须**达到与 FEAT-002 FR-009/FR-011 **同级**的 IFD 与 MakerNote 字段级可读要求。
- **FR-015**：对含 PAR-HEIC-C07 的文件，**视频轨与音频轨须为并列节点**，不得合并为单一「媒体」节点而不区分类型。
- **FR-003**：用户选中分区时，系统**必须**判定负载类型（图片/视频/音频/文本·元数据/其他，含辅助图子类型）并调用 FEAT-004。
- **FR-004**：对图片类项，系统**必须**提供 FEAT-004 静态预览所需引用；对视频类项（含运动影像），**必须**提供可播放预览引用。
- **FR-005**：当当前浏览器环境不属于 §浏览器支持环境 中声明可完整支持的范围时，系统**必须**说明不支持原因并给出建议环境（ENV-HEIC-A/B/C），**不得**空白或无限加载。
- **FR-006**：对无法解析的盒子/项，系统**必须**标注警告并允许查看可读说明或失败原因。
- **FR-007**：解析完成后**必须**向 FEAT-001 回传成功/部分成功/失败及原因。
- **FR-008**：在声明支持的环境内，HEIC 分区浏览交互口径**必须**与 JPEG（FEAT-002）一致：选中即呈现、错误提示类别一致（由 FEAT-004 统一文案）。

### NFR（Non-Functional Requirements）

- **NFR-PERF-001**：对 ≤ **20MB** 标准 HEIC 样例，在**支持环境**内分区列表首次完整渲染 **P95 ≤ 10 秒**。
- **NFR-PERF-002**：分区选中到呈现触发 **P95 ≤ 500ms**（不含媒体解码）。
- **NFR-POWER-001**：**N/A**——Web 端；支持取消长时解析。
- **NFR-MEM-001**：解析 ≤ **20MB** HEIC 时，本 Feature 额外内存峰值 **≤ 200MB**（相对基线）。
- **NFR-SEC-001**：同 FEAT-002；不得外传文件内容。
- **NFR-OBS-001**：须区分「环境不支持」与「文件损坏」失败类型，供测试统计。
- **NFR-REL-001**：支持环境内标准样例集（≥ **10** 个 HEIC）主要层级正确率 **≥ 95%**；含视频轨样例中 **≥ 90%** 可起播 **≥ 3 秒**（与 EPIC/FEAT-004 一致）；不支持环境 **100%** 显示 FR-005 说明。

## AC（验收标准）*（必填）*

- **AC-001**：ENV-HEIC-A 下 S-HEIC-01～03 对 P0 **100%**；完整样例集 P0 **100%**、P1 **≥ 95%**（引用 FR-002）。
