# EPIC 规格说明：贪食蛇网页游戏

**EPIC ID**：EPIC-006
**EPIC Version**：v0.1.0
**创建时间**：2026-06-28

**输入**：`"生成一个前端网站，该网站可以用来玩贪食蛇游戏。"`

## 背景、目标与价值 *（必填）*

- **背景**：用户希望在浏览器中直接体验经典贪食蛇游戏，无需安装客户端。
- **目标**：交付一个可在现代浏览器中打开、即开即玩的贪食蛇网页应用。
- **价值**：提供轻量、零安装的休闲娱乐入口；可作为 Verity 仓库 Web 前端示例项目。
- **产品竞争力**：经典玩法 + 简洁现代界面；支持键盘操作与触屏方向键（可选增强）。
- **技术竞争力**：纯前端、无后端依赖；可静态部署。
- **成功标准（EPIC Level）**：用户在浏览器打开页面后 3 秒内可开始第一局游戏；核心玩法（移动、吃食物、撞墙/自身结束）完整可用。

## 范围 *（必填）*

- **In Scope**：单页贪食蛇游戏；开始/暂停/重新开始；计分；游戏结束提示。
- **Out of Scope**：用户账号与登录；排行榜与云端存档；多人对战；移动端原生 App；后端服务。
- **上项范围**：
  - 地区：全球（Web）
  - 销售渠道：Web 浏览器访问
  - 设备类型：桌面浏览器为主，移动端浏览器基本可用
  - 机型定位：通用
  - OS 版本：现代浏览器（近 2 年主流版本）
  - 保密等级：公开
- **上项节奏**：一次性交付 MVP

## 约束与假设 *（必填）*

- **约束**：纯前端实现；须可在本地开发与静态构建后部署；遵循 Verity 仓库 apps/ 子项目组织方式。
- **假设**：用户具备键盘或屏幕触控能力；无网络时本地打开构建产物仍可游玩（离线静态资源）。

#### FEAT-001 - 贪食蛇网页游戏

- **类型**：Product
- **用户价值**：用户在浏览器中即可游玩经典贪食蛇，获得分数反馈与重新开始能力。
