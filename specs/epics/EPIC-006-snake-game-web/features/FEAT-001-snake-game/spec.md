## FR / NFR *（必填）*

### FR（Functional Requirements）

- **FR-001**：用户打开页面后，可看到游戏棋盘、当前分数与操作说明。
- **FR-002**：用户可通过方向键（上/下/左/右）控制蛇的移动方向；蛇按固定节奏自动前进。
- **FR-003**：蛇吃到食物后，蛇身增长一格，分数增加，并在棋盘上随机生成新食物（不与蛇身重叠）。
- **FR-004**：蛇撞墙或撞到自身时，游戏结束，显示最终分数，并提供重新开始入口。
- **FR-005**：用户可暂停与继续游戏；暂停时蛇停止移动，界面显示暂停状态。
- **FR-006**：游戏结束后，用户可重新开始新一局，分数归零，蛇与食物重置为初始状态。

### NFR（Non-Functional Requirements）

- **NFR-PERF-001**：首屏加载至可开始游戏 ≤ 3 秒（本地 dev 环境，常规桌面浏览器）。
- **NFR-PERF-002**：游戏 tick 间隔稳定，肉眼无卡顿（目标 8–12 tick/s）。
- **NFR-MEM-001**：单页内存占用增量 ≤ 50 MB（游戏运行期间）。
- **NFR-SEC-001**：不收集用户个人信息；无外部网络请求（静态资源除外）。
- **NFR-OBS-001**：N/A（无埋点要求）。
- **NFR-REL-001**：浏览器标签页切换后再返回，游戏状态保持（暂停态或进行中）；刷新页面则重置。

## AC（验收标准）*（必填）*

- **AC-001**：打开页面 3 秒内可见棋盘并开始移动（FR-001, NFR-PERF-001）。
- **AC-002**：按方向键可改变蛇方向，蛇不能立即反向（FR-002）。
- **AC-003**：吃到食物后蛇变长、分数 +1、新食物出现（FR-003）。
- **AC-004**：撞墙或撞自身后显示游戏结束与分数，可点击/按键重新开始（FR-004, FR-006）。
- **AC-005**：按空格或暂停按钮可暂停/继续（FR-005）。
- **AC-006**：`npm run build` 构建成功，`npm test` 核心逻辑测试通过。
