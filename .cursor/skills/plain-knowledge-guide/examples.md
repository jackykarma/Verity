# 示例触发方式

下面这些请求都适合触发 `plain-knowledge-guide`：

## 直接了解型

- `快速了解一下区块链`
- `通俗解释什么是熵`
- `白话讲讲什么是机会成本`
- `轻松理解一下黑洞`

## 想听人话型

- `别太学术，给我讲明白什么是微服务`
- `像给朋友解释一样说说缓存雪崩`
- `用比喻讲清楚什么是向量数据库`
- `不要太深入，先让我看懂 MCP`

## 想要一篇总览型

- `给我一篇容易懂的 AI 总览`
- `写一篇图文并茂的相对论介绍`
- `帮我整理一篇产品经理是什么的说明文`
- `用一篇文档讲清楚什么是存在主义`

## 预期输出特征

输出应满足：

- 只生成 `1` 篇 Markdown 文档
- 直接保存到 `docs/learn/轻松懂知识/[主题名].md`（一篇文档一个知识，不建子目录）
- 有白话解释
- 有类比或比喻
- 有至少 `1` 个 Mermaid 图
- 有误区提醒
- 有“如果只记 3 句话”的总结

## 不适合本 skill 的请求

下面这些请求更适合别的学习类 skill：

- `系统学习 Transformer`
- `给我做一个 6 篇的学习包`
- `按入门到深入给我出学习地图`
- `要能实战落地，还要带练习题和作业`

这类需求已经超出“平时先了解一下”的范围。
