# API 接口文档模板

> 本文件包含**两套**模板，用于「业务功能文档套件」的「接口文档」部分：
> - **模板 A：依赖的后端接口文档** —— 文件名 `依赖后端接口.md`，描述本工程**调用的外部 REST/HTTP 服务端 API**（请求/响应/字段/错误码）。
> - **模板 B：对外提供的代码接口文档** —— 文件名 `对外提供接口.md`，描述本模块**对外暴露的 Kotlin/Java 公共接口、SDK API、回调契约**。
>
> 选用原则：纯客户端模块只需模板 B；纯接入后端的模块只需模板 A；两者都有则各产一篇。
> 接口数量多时按业务域拆分为多篇（如 `依赖后端接口-用户.md`、`依赖后端接口-订单.md`），避免单文件过大。
> 非 REST 协议（gRPC / WebSocket / 长连接推送 / MQTT 等）同样用模板 A 记录：把 Method/Path 替换为「协议 + 服务/方法名或 Topic」，请求/响应表改为消息体字段表，并补充连接生命周期（建连/心跳/重连/断开）说明。

### 请求

**Headers**

| 名称 | 必填 | 说明 |
|------|------|------|
| Content-Type | 是 | application/json |
| Authorization | 否 | 登录接口无需 |

**Path / Query 参数**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| page | query | int | 否 | 页码，从 1 开始 |

**Body**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码（已加密） |

```json
{
  "username": "alice",
  "password": "******"
}
```

### 响应

**成功（200）**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.token | string | 访问令牌 |
| data.expiresIn | int | 过期秒数 |

```json
{
  "code": 0,
  "message": "ok",
  "data": { "token": "xxx", "expiresIn": 7200 }
}
```

**错误码**

| HTTP / code | 含义 | 触发场景 | 客户端处理 |
|-------------|------|----------|------------|
| 401 / 1001 | 账号或密码错误 | ... | 提示重新输入 |
| 429 / 1002 | 请求过于频繁 | ... | 退避重试 |
| 5xx | 服务端异常 | ... | 兜底提示 + 重试 |

### 对应的客户端数据模型

```kotlin
data class LoginResponse(
    val token: String,
    val expiresIn: Int,
)
```
