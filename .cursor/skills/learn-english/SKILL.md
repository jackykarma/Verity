# 英语学习

围绕英语主题输出可学习文档，帮助用户建立"理解、辨析、输入、输出、练习、复盘"的闭环。

---

## 学习方法

始终遵循以下方法：

1. 先激活用户的已有认知和表达习惯，再建立新的语言模式。
2. 以"可理解输入 + 可输出表达"为主线，而不是只背规则。
3. 先解释意义和使用场景，再讲规则和形式。
4. 用最小对比帮助区分相近词、相近语法和相近表达。
5. 用例句和改写帮助迁移，而不是只给定义。
6. 用费曼式输出检验理解——能用英文说清楚才算真懂。
7. 用主动回忆和间隔复习固化语言记忆。

---

## 问题前置：学习前先提问（子主题级必做）

**这是最重要的一步，不可省略。**

当用户明确了要学的子主题时，在生成任何学习内容之前，必须先进入"问题前置"环节。

### 问题前置的目的

- 了解用户的起点，避免重复用户已知的内容
- 把用户的真实困惑和表达障碍转化为学习主线
- 为后续"验收"提供基准：学完后回头看，哪些问题答了、哪些还没答

### 如何提问

围绕主题，从以下维度主动向用户提问，问题数量不设上限，覆盖所有对学习有价值的角度：

**1. 已有认知探底**
- 你对这个语法点 / 词 / 表达，目前了解多少？
- 你现在英语大概什么水平？有没有用过这个表达？
- 你能尝试用英文说一个相关的句子吗？

**2. 问题与困惑收集**
- 你最想搞清楚的是什么？
- 这个知识点在什么情况下让你感到困惑或出错？
- 你有没有见过用法让你费解的句子？
- 你最容易混淆的相近词或表达是什么？

**3. 学习目标锚定**
- 学完这个主题，你希望能做到什么？（能正确使用？能听懂？能写出来？）
- 你是为了日常口语、技术英语、写作，还是考试？
- 你学完后打算在什么场景里用它？

**4. 场景与背景锚定**
- 你有没有遇到因为这个知识点没搞清楚而犯错的具体情况？
- 你最近在读 / 写什么英语内容？

**5. 主题专属深挖问题**

根据具体主题补充针对性问题，以下是常见主题示例，实际执行时应根据主题动态生成：

- **时态（如一般过去时）**：你知道一般过去时和现在完成时的核心区别吗？你会拼写不规则动词吗？你有没有遇到不确定用哪个时态的情况？
- **虚拟语气**：你知道虚拟语气是用来表达什么的吗？你见过 "If I were you..." 这种表达吗？你知道和真实条件句有什么区别吗？
- **词汇辨析（如 affect vs effect）**：你知道这两个词的词性吗？你能造一个句子用其中一个吗？你在哪个场景下见过它们？
- **技术英语阅读**：你通常读什么类型的技术文档？你在读文档时遇到的最大障碍是什么？你最不确定如何处理的句型是什么？
- **口语表达**：你最缺的是词汇量、语法准确性，还是流利度？你有没有想表达但不知道怎么说的典型场景？

**提问格式要求**：

把所有问题一次性列出，编号呈现。不要分批问，不要先给答案，等用户统一回答后再继续。示例：

```
在开始之前，我想先了解你目前对这个主题的掌握情况，帮我生成更贴合你需求的学习内容：

1. 你对虚拟语气目前了解多少？
2. 你能尝试写一个含虚拟语气的句子吗？
3. 你最想搞清楚的是什么？
4. 你知道虚拟语气和直陈语气的区别是什么吗？
5. 你有没有遇到不确定该用哪种语气的情况？
6. 你是为了写作、口语、还是考试来学这个？
7. 你在什么场景下最容易用错？
8. ...（根据主题继续补充）

请直接回答你知道的，不知道的就说不知道，都没关系。
```

### 收到用户回答后

根据用户的回答做以下处理：

1. **识别起点**：用户已经掌握什么，不需要从零讲
2. **提炼问题清单**：把用户的困惑和想搞清楚的问题整理成"本次学习的问题清单"
3. **调整内容侧重**：用户不会的地方多讲，已会的快速确认或跳过
4. **在文档开头放问题清单**：作为学习主线，并在结尾逐一检验

## 默认行为

如果用户只输入一个领域或主题，没有补充更多要求，默认按以下规则执行：

- 学习程度默认使用 `系统深入`
- 学习目标默认包含：`能讲给别人听`、`能实战`、`能画图`
- 子主题级输入：先进入问题前置环节，再生成内容
- 领域级输入：先生成学习地图，等待用户选择子主题

---

## 输入要求

至少明确以下信息；如果用户未明确补充，则使用默认行为：

- 输入层级：`领域` 或 `子主题`
- 学习主题：如 `一般过去时`、`虚拟语气`、`技术英语阅读`、`发音连读`
- 学习深度：默认 `deep`
- 学习目标：默认是"能讲给别人听、能实战、能画图"

如果输入的是大领域，如 `英语`、`技术英语`、`英语口语`、`英语语法`，不要直接展开多篇正文，先产出学习地图，再让用户选择子主题。
如果主题过大，优先缩小到一个语法点、一个表达族、一个技能点或一个场景。

---

## 输出策略

先判断当前输入属于哪一层：

### 领域级输入

当用户输入的是领域而不是单一主题时，先输出 1 篇 `领域学习地图.md`，不要直接展开多个子主题正文。

`领域学习地图.md` 必须包含：

- 这个领域在学什么
- 为什么值得学
- 适合什么目标的人学习
- 前置知识
- 知识树或主题树
- 推荐学习顺序
- 子主题分级与标签
- 每个子主题解决什么问题
- 哪些主题适合先学
- 下一步可选输出主题

学习地图中的每个子主题都尽量标注以下信息：

- 难度：`入门`、`进阶`、`深入`
- 优先级：`建议优先`、`按需学习`、`可后置`
- 适合目标：如"打基础""提升阅读""提升表达""应对考试"
- 前置知识：进入该主题前最好先掌握什么
- 是否可跳过：`否`、`部分可跳过`、`可跳过`
- 产出收益：学完后能解决什么问题

如果用户没有指定子主题，就停在学习地图这一层，等待用户选择下一步。

### 子主题级输入

当用户输入的是明确子主题，如 `虚拟语气`、`一般过去时`、`技术英语阅读`、`连读`，先进入问题前置环节，再根据深度输出 `主题总览.md` 或多篇学习包。

## 输出模式

以下模式仅适用于"已经明确子主题"的情况：

### `quick`

输出 1 篇 Markdown 文档，帮助用户快速理解并马上上手练习。文件名必须使用中文，默认使用 `主题总览.md`。

### `deep`

输出 3~6 篇 Markdown 文档，组成学习包。文件名必须使用中文。默认建议文件：

- `00-学习地图.md`
- `01-背景含义与核心规则.md`
- `02-用法模式与对比辨析.md`
- `03-输入输出与练习.md`
- `04-常见错误与纠正.md`
- `05-自测与延伸学习.md`

## 文件命名与配图要求

- 所有学习文档统一输出到 `docs/learn/英语/` 目录下。
- 领域级文档默认保存为 `docs/learn/英语/领域学习地图.md`。
- 子主题级文档必须按主题创建子目录，保存到 `docs/learn/英语/[子主题名]/` 下。
- `quick` 模式默认保存为 `docs/learn/英语/[子主题名]/主题总览.md`。
- `deep` 模式默认保存为 `docs/learn/英语/[子主题名]/` 下的多篇结构化文档。
- 输出的 Markdown 文件名必须使用中文，不使用英文语义文件名。
- 文件名可以包含数字前缀以表达学习顺序，如 `00-学习地图.md`、`01-背景含义与核心规则.md`。
- 图示默认优先使用 Mermaid，尤其适用于语法结构图、时态对比图、表达关系图、学习路径图和复习时间线。
- 当 Mermaid 难以表达口型示意、音标发音部位图、教材截图或权威语法图表时，可以从网络抓取图片辅助讲解。
- 网络图片优先选择权威词典、官方教材平台、语言学习机构、大学课程资料或公开教育资源中的图片。
- 使用网络图片时，必须在文档中标注来源链接、图片用途，并简要说明该图片帮助理解什么。
- 对来源不明、版权不清晰、内容失真或营销性质过强的图片，不要使用；此时退回 Mermaid 或文字说明。

## 通用写作要求

每篇文档都应尽量包含：

- 一句话理解
- 这个知识点解决什么表达问题
- 核心规则或核心意义
- 常见场景
- 正确例句和错误例句
- 常见误区
- 练习题

不要把英语学习写成纯规则罗列。必须补充真实表达语境。

## 8. 三层自检

### 第一层：主动回忆（先不看前面内容）
合上文档，用自己的话（或直接用英文）回答：
- 这个表达/语法点的核心用途是什么？
- 什么情况下用，什么情况下不用？
- 它和最容易混淆的那个表达的区别是什么？

写完后对照文档，标出哪里记错了。

### 第二层：费曼输出
尝试用英文写 2~3 个句子，展示你对这个知识点的理解。
不用完美，但要用自己的话，不能直接抄例句。

如果写不出来 = 还没真正掌握，回去再看，再试一次。

### 第三层：应用与迁移
- 你能在真实对话、邮件或文章中造一个自然的句子吗？
- 你能找到一个你之前写错或说错的地方来修改吗？
- 你能给一个不懂这个语法的朋友解释清楚吗？
